# ST00 deterministic SOURCE region corpus

`src/diagnostics/tests/superterrain/corpus/` includes thirteen little-endian synthetic region inputs and one hash index. They are **not** textures extracted from the user's game and **not** visual material parity references. They exercise source codec and region semantics that ST01–ST04 need to preserve. The working game/asset tree is absent from this handoff; ST01 must obtain or create a separate canonical-render comparison corpus before its acceptance gate.

## Binary format `.st00region`

32-byte little-endian header: `<4sHHHHIIIQ>` = magic `ST0R` (bytes 0–3), u16 version 1 (4–5), u16 side=128 (6–7), u16 map index (8–9), u16 flags (10–11: 1=present, 2=has derived RG8), u32 payload bytes (12–15), u32 CRC32 payload (16–19), u32 reserved=0 (20–23), u64 first eight SHA-256 payload bytes interpreted little-endian (24–31). Absence has zero payload and unset present flag. These are **test inputs** only, not the new shipping package format.

Each present region has contiguous row-major planes at fixed offsets from payload start: R16 height 32,768 bytes (little endian, globally normalized [-384,768]), control RF32 **bit pattern** 65,536 bytes little endian, color RGBA8 65,536 bytes, derived normals RG8 32,768 bytes. Exact total payload 196,608 bytes. Synthetic RG8 derived normals are illustrative and should be regenerated by the production derived-map builder for canonical comparisons. The file hash is recorded in `corpus/index.json`.

## Fixtures and intended tests

| Fixture | Stress |
| --- | --- |
| `absent` | Missing logical region; no root or fake height |
| `empty_holes` | Present all-hole region, mask sentinel and solidity |
| `flat` | Global R16 zero height, implicit-safe controls |
| `negative_steep` | Height at -384 m and steep quantized transitions |
| `cliff` | Large height step, mip reduction and mixed mask behavior |
| `border_west`, `border_east` | Full 128-row bit-identical touching height borders; adjacent region indices |
| `coverage_edges` | Eight-texel hole checker, touches mask page boundaries and transitions |
| `alpha_extremes` | Authored alpha8 = 0, 85, 170, 255 mapping to alpha2 = 0, 1, 2, 3 |
| `sparse_controls` | Four isolated material IDs 31/30 and controls otherwise mostly automatic |
| `wet_surface` | Alpha gradient and metadata requiring wetness material parity |
| `rotated_slopes` | All 16 UV rotations, all 8 scales, varying auto control and slope |
| `distance_regimes` | One consistent source field sampled from 8 m, 150 m and 1100 m |

## Frozen semantic probes

- Height `-384` encodes to `0x0000`; `0` to `0x5555`; `768` to `0xffff`; one R16 LSB in this codebase is `1152 / 65535 = 0.017578392m`. In the synthetic negative slope fixture, texel (0,0) encodes to zero.
- All 128 row positions satisfy `border_west(127,y).heightR16 == border_east(0,y).heightR16`. This is a byte-for-byte fixture condition, **not** a proof that arbitrary authored neighbors currently match.
- `alpha_extremes` x ranges 0–31, 32–63, 64–95, 96–127 map to two authored-alpha bits 0,1,2,3; cutout bit follows control hole bit independently.
- In `coverage_edges`, (63,0) is solid and (64,0) is a hole. In `empty_holes`, every texel is non-solid and its color alpha remains a separate authored input.
- In `rotated_slopes`, control at (127,127) has UV rotation 15 and scale 7. `sparse_controls` uses base31, overlay30 at (63,63) and implicit auto at (44,44).
- The ST00 Python test fully round-trips **all 196,608 present-region texels** into three 64x64 exact bitplanes and compares every bit to the uncompressed control/color sources (12 x 128 x 128). The standalone C++ test independently checks page IDs, mask bit addressing and the generation gate.

`corpus.py --write` deliberately regenerates this corpus. Without `--write`, it regenerates **in memory** and fails on any byte drift. The frozen manifest hashes protect against changing generation math unnoticed; production acceptance additionally requires outputs from the real canonical material evaluator, actual BC compressor and GPU samplers.
